- Important: Liveness vs readiness

    Since you've already built the health APIs, this is where we make them useful for deployment.

    We should distinguish:
        Liveness
        "Is the Node process alive?"

        Readiness
        "Can this API actually serve traffic?"

    That's an important distinction.
    Liveness
    Your liveness endpoint should not query PostgreSQL.
